# New Capitol Area Council Website Prototype

Static GitHub Pages deployment of the Capitol Area Council homepage modernization concept.

This prototype uses the CAC logo, topo background pattern, and brand palette to demonstrate a cleaner homepage structure for families, volunteers, events, programs, and leader resources.

Photography used in the prototype is sourced from the Capitol Area Council Flickr albums at https://www.flickr.com/photos/capitolareacouncil/albums/.
